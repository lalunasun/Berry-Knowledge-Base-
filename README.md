# Berry-Knowledge-Base-
A email knowledge base for sales training and customer communication.

## 🌸 Overview

StrawberryCRM is a lightweight system that converts Outlook emails into a structured local knowledge base.

The goal is to help sales teams, especially new employees, quickly understand past customer interactions, ongoing projects, and communication patterns by learning directly from historical emails.

---

## 🍓 What It Does (V1)

- Export emails from Outlook as `.msg` files
- Parse email data using Python
- Convert emails into structured JSON format
- Classify emails into different types (inquiry, reply, approval, system, etc.)
- Extract key customer information from inquiry emails
- Build a searchable local dataset for training and reference

---

## 🌼 Use Cases

- New employee onboarding and training
- Reviewing past customer inquiries
- Understanding order, payment, and production progress
- Learning from previous email responses
- Building reusable reply patterns
